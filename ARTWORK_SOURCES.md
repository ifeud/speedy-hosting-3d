# Original artwork record

Created on **September 30, 2026** for the independent Speedy Hosting concept.

The current site uses **no publisher promotional images, logos, screenshots or game texture files**. Earlier official-image experiments were removed from the active source package at the user's request.

## Seven newly generated environments

| File | Original scene |
| --- | --- |
| `assets/v4/hero-world.png` | River valley, angular mountain lodge, stone escarpment and bridge |
| `assets/v4/builders-world.png` | Riverside village, limestone house, terracotta roof and geometric cypress trees |
| `assets/v4/industrial-world.png` | Coastal relay station, original concrete structures and radio antenna |
| `assets/v4/companions-world.png` | Emerald settlement, waterfall and original lavender-stone arch; no characters or creatures |
| `assets/v4/nordic-world.png` | Nordic timber settlement and fjord |
| `assets/v4/cavern-world.png` | Amber crystal cavern, pool, bridge and small explorer shelter |
| `assets/v4/prehistoric-world.png` | Prehistoric river valley and a generic herbivorous dinosaur |

All images were generated as new scenes. Prompts excluded proprietary game characters, logos, recognizable branded objects, existing game textures, UI graphics and reconstructions of published key art. The fantasy environment was additionally edited to remove every visible creature or face.

The broad cube-based environment style is the intended inspiration. These are not represented as actual game footage, official artwork or endorsements. Game names are used beside the illustrations to identify supported software only.

`assets/v4/artwork-manifest.json` records local files, original PNG dimensions and SHA256 hashes. Compressed derivatives are embedded directly in the standalone HTML.

The hardware feature is authored Three.js geometry with an original SVG fallback. Its source is included. Fonts and icons have explicit open licenses.
